How to Request Documents

  1. Go to the Request Form by clicking the button "Request New Document"
  2. Select the document(s) you need from the available list in the "Catalog" tab
  3. Specify quantity and purpose of your request
  4. Review calculated fees based on the official ARC fee schedule
  5. Submit your request for processing by ARC
  6. Track status in this dashboard under "My Request" tab

Note: Processing times vary by document type. Most documents require 15 working days. Authentication services are faster.
